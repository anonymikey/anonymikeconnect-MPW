SUPA LAN Bridge

Windows Bridge · Local bridge: 192.168.10.1:8765

CHECK LOCALLY
Status must be checked from the Windows PC

The Windows bridge must be running for automatic free-access SMS confirmation. It reads authenticated MyPublicWiFi sessions locally and securely reports qualifying sessions to SUPA LAN.

Bridge files are currently stored in Desktop\\SupaLanBridge-Windows.
  • mypublicwifi-bridge.py
  • config.json
  • README-Windows.md
  • config.example.json

Important: The buttons above copy commands for the Windows PC. A normal browser cannot directly launch PowerShell on your computer. For permanent operation, the bridge should eventually run automatically as a Windows background task/service.

Automatic Startup

Download the one-time Windows Task Scheduler setup, then run it as Administrator. It uses the existing bridge and keeps the bridge running in the background.
