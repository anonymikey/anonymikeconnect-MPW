How delivery works

Client SMS

After a voucher is assigned, the client receives the purchase confirmation template with the voucher and package details.

Admin SMS

The configured admin number receives a sale alert with the customer, package, voucher, amount, and client phone.

Status meaning

SENT means TextSMS accepted the request. FAILED means the provider rejected it or the request could not be completed. DELIVERY RECEIPTS are not exposed by the current TextSMS account.
